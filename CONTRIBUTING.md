## Development Workflow

1. Fork repository
2. Create feature branch

```bash
git checkout -b feature/my-feature
```

3. Make changes
4. Commit changes

```bash
git commit -m "feat: add context weighting"
```

5. Push branch
6. Open Pull Request

---

## Commit Convention

Use Conventional Commits.

Examples:

```text
feat: add query rewriting engine
fix: correct context scoring bug
docs: update architecture documentation
refactor: simplify adapter interface
test: add context engine tests
```

---

## Pull Request Guidelines

Keep PRs:

* Small
* Focused
* Well documented

* Problem statement

* Impact
