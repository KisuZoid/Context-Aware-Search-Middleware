# Vision

## The Problem

Modern applications heavily personalize:

* Recommendations
* Homepages
* Notifications
* Advertising

Yet search is still largely query-driven.

Most search systems understand:

```text
query
```

But users search with:

```text
query + context
```

Context includes:

* Current category
* Current page
* Session behavior
* User preferences
* Business objectives

As a result, search relevance is often lower than user expectations.

---

## Our Thesis

User intent cannot be derived from the query alone.

The same query can mean different things in different contexts.

Example:

```text
charger
```

Could mean:

* Phone charger
* Laptop charger
* EV charger
* Toy charger

Intent depends on context.

---

## Our Mission

Build the open standard for contextual search.

Applications should not need to replace their existing search stack.

Instead they should simply provide context.

---

## Long-Term Vision

Become the infrastructure layer between applications and search providers.

Just as:

* Stripe standardized payments
* Segment standardized analytics
* OpenTelemetry standardized observability

CASM aims to standardize search context.
